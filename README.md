# Padasala - Modern Education Platform

India's modern education platform connecting students, parents, schools, teachers and tuition centres. Discover verified schools, prepare for NEET & JEE, apply for teaching jobs, join skill classes, and never miss a school event.

## 🚀 Features

- **Top Navigation**: Responsive rounded glassmorphic navigation bar.
- **Interactive Hero Screen**: Rich 3D educational environment with glowing effects, floating origami paper plane, 3D graduation cap, and smooth animations.
- **Search & Discovery**: Category search across Schools, Courses, Teacher Jobs, and Events with city filters.
- **Quick Action Cards**: Dedicated portals for Schools and Teachers.
- **Boards & Skills We Cover**: Continuous marquee slider covering CBSE, State Board, NEET, JEE Prep, Chess, Silambam, Yoga, Spoken English, Robotics, and Coding.
- **Responsive Design**: Designed for desktop, laptop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS & Lucide Icons
- **Slider**: React Fast Marquee

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/sjgokul12/Padasala.git

# Install dependencies
npm install

# Run the local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
